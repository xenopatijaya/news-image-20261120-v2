# The World in One Day — Friday 20 November 2026

One image summing up the world's news of Friday 20 November 2026: a
1024x1024 front page with three illustrated leads (Cyclone Akvan's
landfall, the missile barrage on Kyiv, and Asia's AI sell-off), ten
illustrated feature cards, a dotted world map with pins 1-13, a strip of
the day's key numbers, 23 numbered briefs in Also on Friday, and an
explicit date-check strip naming the Thursday stories deliberately left
out — 36 stories across every region. Built for the
[make.fun](https://make.fun/bounty/news-image-20261120) bounty
`news-image-20261120`.

`main.py` (Python 3, standard library + Pillow) draws `entry.png`
deterministically — no network, no randomness, no clock — and writes it
to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
